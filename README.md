# Position pour iPhone

Aperçu de l'interface Position pour iPhone. L'application complète tourne sur le PC avec start.bat.

## Télécharger l'outil PC

Sur la page du dépôt, clique sur le bouton vert **Code**, puis sur **Download ZIP**. Décompresse l'archive, ouvre le dossier `outil-pc` et double-clique sur `start.bat`. Le mode d'emploi complet est dans `outil-pc/README_FR.md`.
